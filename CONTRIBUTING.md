# Contributing to Life RPG

Thank you for your interest in contributing to Life RPG! 🏰

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/life-rpg.git`
3. Create a feature branch: `git checkout -b feat/my-feature`
4. Make your changes
5. Commit with descriptive messages: `git commit -m "feat: add X feature"`
6. Push to your fork: `git push origin feat/my-feature`
7. Open a Pull Request

## Commit Convention

We use Conventional Commits:
- `feat:` — new feature
- `fix:` — bug fix
- `ui:` — UI/styling changes
- `refactor:` — code refactoring
- `docs:` — documentation
- `perf:` — performance
- `a11y:` — accessibility
- `seo:` — SEO improvements
- `config:` — configuration
